# Advertising Website – Box Model Demo

This project is a simple advertising-style webpage built using **HTML5** and **CSS3**.  
It demonstrates the **CSS Box Model**, the use of **selectors**, and proper structuring of a webpage with external styling.  
The website includes text, navigation, images, audio, and video to showcase how media can be embedded in modern web pages.
